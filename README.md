# Connect Four (Четыре в ряд)

## О проекте
Это веб-игра "Четыре в ряд", созданная как интерактивное приложение с возможностью игры против другого игрока или против AI.

## Функционал
- Игра для двух игроков (PvP)
- Режим игры против AI (PvAI)
- Разные уровни сложности AI (Easy, Medium, Hard)
- Гравитация фишек (они падают вниз)
- Определение победителя (4 в ряд)
- Подсветка победной комбинации
- Сохранение состояния игры (LocalStorage)
- Современный интерфейс и темы оформления

## Дополнительно
- PRO-режим с подсказками ходов (демо-функция)
- Локальный AI без использования внешних API
- Адаптивный дизайн

## Цель проекта
Проект показывает навыки разработки интерактивных веб-приложений, работу с игровой логикой, UI и базовыми алгоритмами искусственного интеллекта.
